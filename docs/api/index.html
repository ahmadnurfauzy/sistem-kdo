Introduction

REST API Sistem Pengelolaan Kendaraan Dinas Operasional (KDO) Perangkat Daerah — JP-1 (20270311).

Base URL: http://localhost:8000 
API ini digunakan untuk mengelola data kendaraan dinas operasional (KDO) milik perangkat daerah,
mencakup pendataan kendaraan beserta kondisinya, data pegawai negeri sipil (PNS) selaku
penanggung jawab penggunaan, serta data perangkat daerah (instansi).

Seluruh endpoint (kecuali login) membutuhkan bearer token Sanctum. Role **admin** dapat
melakukan seluruh aksi, sedangkan **viewer** hanya dapat membaca data.

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {YOUR_AUTH_KEY}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

You can retrieve your token by visiting your dashboard and clicking Generate API token.

Autentikasi

Login pengguna

Login dengan email dan password untuk mendapatkan bearer token. Token dipakai pada seluruh endpoint lain melalui header Authorization: Bearer {token}.

Example request:
curl --request POST \
    "http://localhost:8000/api/v1/auth/login" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"email\": \"admin@kdo.test\",
    \"password\": \"password123\"
}"

const url = new URL(
    "http://localhost:8000/api/v1/auth/login"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "email": "admin@kdo.test",
    "password": "password123"
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());

Example response (200):


{
    "message": "Login berhasil.",
    "data": {
        "token": "1|abc...",
        "user": {
            "id": 1,
            "name": "Administrator KDO",

    }
}

    --get "http://localhost:8000/api/v1/kendaraan?search=avanza&kondisi=rusak_berat&perangkat_daerah_id=1&per_page=15" \
    --header "Authorization: Bearer {YOUR_AUTH_KEY}" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json"
const url = new URL(
    "http://localhost:8000/api/v1/kendaraan"
);

const params = {
    "search": "avanza",
    "kondisi": "rusak_berat",
    "perangkat_daerah_id": "1",
    "per_page": "15",
};
Object.keys(params)
    .forEach(key => url.searchParams.append(key, params[key]));

const headers = {
    "Authorization": "Bearer {YOUR_AUTH_KEY}",
    "Content-Type": "application/json",
    "Accept": "application/json",
};


fetch(url, {
    method: "GET",
    headers,
}).then(response => response.json());
